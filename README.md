# Retro Forum UI

A retro-styled forum interface: a thread feed with thread cards, search, left/right sidebars and a new-thread button. Frontend-only UI project, no backend.

## Stack

Vite + React 18 + TypeScript + Tailwind CSS + shadcn/ui

## What's inside

- Thread feed with thread cards
- Search bar and top navigation
- Left and right sidebars, mobile navigation
- Light/dark theme toggle

## Develop

```bash
npm install
npm run dev     # dev server
npm run build   # production build
npm run lint    # eslint
```
